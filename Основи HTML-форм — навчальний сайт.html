Вітаю на сайті про HTML-форми

Форми дозволяють користувачеві надсилати дані на сервер: логін і пароль, відповіді в анкеті, коментар чи файл. На сайті зібрано матеріали, які допоможуть розібратися з формами від нуля до готової анкети.

Що тут є

  • Теорія: тег form, основні поля введення та їхні атрибути.
  • Практика: готовий код анкети й така сама форма, яку можна випробувати.
  • Самоперевірка: п’ять запитань із відповідями.
  • Джерела: де читати далі.

Теорія

Тег form

Тег <form> відзначає початок і кінець форми. Форм на сторінці може бути кілька, але вкладати їх одну в одну не можна.

АтрибутПризначення
actionфайл, який обробить дані форми
methodметод запиту: GET (за замовчуванням) або POST
targetде показати результат: у поточному вікні чи новій вкладці
autocompleteкерує автозаповненням полів

Поля введення

Тег <input> одиночний. Тип поля задає type, ім’я для сервера — name, значення — value.

typeЩо створює
textоднорядкове текстове поле
passwordполе пароля, символи замінюються крапками
radioперемикач; із групи з однаковим name обирається лише один
checkboxпрапорець із двома станами
submit / resetкнопки відправки та очищення форми
hiddenприховане поле, яке передається на сервер
fileвибір файлу для завантаження

Інші елементи й атрибути

<select> з <option> створює випадаючий список; selected робить пункт обраним за замовчуванням, multiple дозволяє вибрати кілька пунктів. <textarea rows cols> — багаторядкове поле. <fieldset> з <legend> групує елементи під спільним заголовком. Атрибут maxlength обмежує довжину тексту, size задає ширину поля, checked позначає обраний елемент, disabled робить елемент неактивним, а readonly забороняє змінювати значення.

Практика

Анкета з двома групами полів. Спробуйте заповнити її праворуч від коду або нижче на вузькому екрані.

<form action="#" method="post">
  <fieldset>
    <legend>Особисті дані</legend>
    <label for="n">Ім’я:</label>
    <input type="text" id="n" name="name" size="20" maxlength="30">
    <input type="radio" name="gender" value="m"> Чоловік
    <input type="radio" name="gender" value="f"> Жінка
    <select name="age">
      <option value="u18" selected>до 18</option>
      <option value="18+">18 і старше</option>
    </select>
  </fieldset>
  <fieldset>
    <legend>Мови</legend>
    <input type="checkbox" name="lang" value="java"> Java
    <input type="checkbox" name="lang" value="cs"> C#
  </fieldset>
  <input type="submit" value="Надіслати">
  <input type="reset" value="Очистити">
</form>

Самоперевірка

Дайте відповідь у думці, потім розкрийте запитання.

1. Який тег задає групу елементів із заголовком?

<fieldset> задає групу, а заголовок — вкладений <legend>.

2. Який метод запиту використовується за замовчуванням?

GET.

3. Як зробити пункт списку обраним за замовчуванням?

Додати до <option> атрибут selected.

4. Чому з кількох перемикачів обирається лише один?

Бо вони мають однакове значення атрибута name і утворюють одну групу.

5. Який атрибут обмежує кількість символів у полі?

maxlength.
